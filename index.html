Auto-Video-Upload

Auto-Video-Upload is a desktop application that allows users to securely upload and publish videos to authorized TikTok accounts using TikTok's official APIs.

Features

  • Secure authentication using TikTok Login Kit (OAuth 2.0)
  • Upload MP4 videos directly from the desktop application
  • Support for TikTok Content Posting API
  • Automatic access token refresh
  • Local storage of authentication tokens

Technology

Auto-Video-Upload is developed in Python and uses the official TikTok APIs to authenticate users and publish content to authorized TikTok accounts.
