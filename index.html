Auto-Video-Upload

Auto-Video-Upload is a desktop application that enables TikTok creators to securely authenticate with TikTok Login Kit and publish videos to their own authorized TikTok accounts using TikTok's official APIs.

Features

  • TikTok Login Kit authentication
  • Secure OAuth authorization
  • Video upload through the Content Posting API
  • Direct publishing to the authenticated user's TikTok account
  • Automatic access token refresh
